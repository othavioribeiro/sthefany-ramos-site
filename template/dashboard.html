Como usar
Passo a passo para entregar um site novo para um cliente.
1

Preencha os dados do cliente

Use o menu lateral para navegar entre as seções. Os campos já estão pré-preenchidos com o exemplo da Sthefany Ramos. Substitua com os dados do novo cliente.

2

Defina cores e tipografia

Use as Paletas Pré-definidas para trocar o tema completo em 1 clique, ou ajuste cor a cor. Escolha as fontes na seção Tipografia.

3

Exporte e salve o JSON

Clique em Exportar JSON para salvar a configuração do cliente. Guarde o arquivo — você pode reimportar para editar depois sem reescrever tudo.

4

Baixe o index.html gerado

Clique em Baixar index.html. O arquivo gerado já tem todas as variáveis CSS e conteúdo do cliente injetados.

5

Monte a pasta do cliente

Crie uma pasta e copie para dentro:
• O index.html gerado
• A pasta css/ (do projeto base)
• A pasta js/ (do projeto base)
• A pasta images/ com as fotos do cliente

6

Hospede no Netlify (gratuito)

Acesse netlify.com, faça login, arraste a pasta do cliente para o deploy. Domínio gratuito *.netlify.app imediatamente. Para domínio próprio, configure o DNS.
